# Specification deltas

This directory records approved changes to established requirements in
[SPEC.md](../SPEC.md).

## Recorded changes

None yet. The initial documentation scaffold is the baseline; it does not change
a previous product specification.

## Workflow

Follow [CONTRIBUTING.md](../CONTRIBUTING.md): propose the affected sections,
previous and revised requirements, rationale, and intended timestamped filename
for review. Obtain explicit user approval before editing the specification,
creating the change record, or implementing conflicting work.

After approval, copy [TEMPLATE.md](TEMPLATE.md) into a file named
`YYYY-MM-DDTHH-MM-SSZ-short-description.md` using the UTC approval timestamp.
Complete the record and update the specification, architecture decision log,
specification change history, and this index together. Preserve historical
decisions and mark superseded requirements.

The template is guidance only; it is not an approved change record. Filling in
an unresolved TBD does not itself contradict an established requirement.
