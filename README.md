## Getting started

Read the contribution guide and relevant specification sections before working.
Define the product scope, first workflow, and acceptance criteria before starting
implementation. Setup and validation commands will be documented when tooling
is selected; there are no application commands to run yet.

`SPEC.md` is the source of truth. TBDs and placeholders are unfinished
documentation, not established requirements. Changes that contradict established
requirements follow the approved delta workflow.
